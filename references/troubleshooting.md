# 故障排查与降级指引（Troubleshooting）

适用版本：与 `SKILL.md` frontmatter 的 `version` 一致（本文件随主版本同步更新，不单独维护版本号，避免与实际版本冲突）。本文件回答一类问题：**出错之后怎么办**。

排查顺序建议固定为三步，避免盲试：

1. 跑一次自检：`python assets/selftest.py`（校验注入、章节数、数据块、色阶同源）。
2. 用报错原文对照下方「30 秒定位表」定位条目。
3. 按该条目的**处置**修复；确实无法修复时走**降级**，并在交付说明中标注受影响范围。

> 原则：宁可降级并显式标注，也不要静默交付一份看起来完整、实则缺章或少表的报告。

## 1. 技能未触发，或按行业咨询作答

**现象**：只问「工程机械行业怎么样」，得到泛行业分析，没有七维度与四大专项。

**原因**：触发词落在行业认知区间，未表达信贷/尽调/授信意图；技能对此设计为「先确认再执行」。

**处置**：把意图说完整，例如「对工程机械及备件制造做**贷前行业尽调**，目标企业徐工，含**企业财务对标与盈亏测算**」。关键词：行业尽调、贷前行业分析、授信前行业研判、行业风险评估。

**降级**：确只需行业认知时，不必触发本技能；直接要「轻量速览版」也可，但需接受无企业对标与无测算。

---

## 2. 完整版却没有企业财务对标

**现象**：维度三只有行业均值，企业值与偏离度两列消失。

**原因**：模板按「有无企业值」自动收放列——`dimensions.profit.items[].ent` 全为空，或整体缺 `company` 节点。

**处置**：
- 核对 `REPORT_DATA.company.items` 是否有 8 项企业指标；
- 核对 `dimensions.profit.items[]` 每项的 `ent` 是否填了企业值；
- 企业数据与行业均值口径不一致时，`dev` 应写「口径不一致-建议复核」，不要强行相减。

**降级**：确无企业数据时，明确走轻量速览版，并在 `header.outputMode` 写「轻量速览版」，同时把专项三 `applicable` 设为 `false`。

---

## 3. 专项三只剩「轻量速览版 · 本行业不适用」

**现象**：完整版、企业数据齐全，但「盈亏测算模板」整章只有一句不适用说明，四张表与盈亏图全无。

**原因**：`special.projectCalc.applicable` 被写成 `false`（或字符串 `"false"`）。这是历史高频故障：该字段一旦为假，整章内容不渲染。

**处置**：
- 改 `applicable` 为布尔 `true`；
- 同时补齐门槛：`params` ≥ 8、`firstYear` ≥ 4、`metrics` ≥ 4、`stress` ≥ 4；
- 跑 `python assets/validate.py <报告.html>`，确认不再报「专项三 applicable=false」。

> 当前模板对「有测算数据但标记为不适用」的冲突数据会照常渲染并给出复核提示，不再静默吞掉整章；校验器则直接判不合格。

**降级**：行业确非项目制（纯贸易/纯服务），改走轻量速览版，并在 `note` 写明「数据缺失-D（轻量版不适用）」。

## 4. 盈亏图为空

**现象**：四张表正常，但「盈亏平衡可视化」整块不出现。

**原因**：`buildBreakeven()` 在参数不足或无法解析时返回 `null`，调用方跳过该图。触发条件为以下任一不成立：设计产能 > 0、产品现货单价 > 0、项目总投资 > 0、年利息支出 > 0、年销售量 > 0、年营业成本 > 0。

**处置**：逐项核对 `params` 与 `firstYear` 中这六项的 `name` 关键词与 `val` 可解析性。数值支持「3500 至 4000」这类区间写法（自动取中值）与「约 911」（自动剥离文字），但必须有数字。

**降级**：保留四张表与文字结论即可，图表属增强项；在交付说明中注明「盈亏图因参数不全未展示」。

## 5. 校验器报「外部依赖」

**现象**：`✗ 校验未通过：外部依赖：<script src= 外部脚本`。

**原因**：模板被误改，引入了 CDN、Web 字体、外链图片或第三方 JS。

**处置**：恢复 `assets/report_template.html` 原文件（本技能要求单文件、零外部依赖、离线可用），不得为美化而加外链。

**降级**：无。此项属硬约束，必须修复后交付。

---

## 6. 校验器报「脚本标签不配平」

**现象**：`<script>` 与 `</script>` 数量不等。

**原因**：`REPORT_DATA` 的某个字符串里含 `</script>`（例如引用了一段 HTML 说明），提前闭合了脚本块。

**处置**：在数据中把 `</script>` 转义为 `<\/script>`，或改写该段文字。

**降级**：无。闭合错误会导致整页脚本失效。

---

## 7. 校验器报「未找到 const REPORT_DATA」

**现象**：页面打开是空白或只有骨架。

**原因**：占位符替换时误删了 `const REPORT_DATA =` 前缀，或替换成了一个非对象字面量。

**处置**：用模板重新注入一次，确保整段形如 `const REPORT_DATA = { … };`，且模板中的 `__REPORT_DATA__` 恰好被替换一次（原模板只保留 1 个占位符）。

**降级**：无。

---

## 8. 页面出现 undefined / NaN

**现象**：某些格子显示 `undefined` 或 `NaN`。

**原因**：数据里缺字段，或该字段本该是数字却写成了无法解析的文本。

**处置**：
- 缺字段按契约补 `null` 或空串（不要省略键名）；
- 数值统一写成「数字 + 单位」分离（`val` 放数值、`unit` 放单位）；
- 复核时先用浏览器打开，确认 `<script>` 之外的正文与 SVG 中无残留（源码里 `return NaN` 等属正常代码，不是页面异常）。

**降级**：模板会把缺值渲染为「—」，但这是兜底不是修复；关键结论缺数据仍须补。

---

## 9. Word 生成失败：No module named 'docx'

**现象**：`ModuleNotFoundError: No module named 'docx'`。

**原因**：未安装 python-docx，或装在了另一个 Python 解释器下。

**处置**：`pip install python-docx`；确认运行脚本的解释器与安装的一致（`python -c "import docx; print(docx.__version__)"` 能输出版本）。可先跑 `python scripts/check_environment.py` 看就绪状态。

**降级**：本次只交付 HTML + XML/Markdown，Word/PDF 待环境就绪后补；在交付说明中注明「Word 版未随附」。

---

## 10. 检索不到数据，来源全空

**现象**：各维度 `source` 为空或只有「数据缺失-C」。

**原因**：网络不可达、数据源限流或未连接结构化接口。

**处置**：
- 先确认可用的结构化数据源（Wind / 同花顺妙想 / 企查查 / 北大法宝等 MCP）；连接后重试；
- 无结构化源时按四级优先级检索：部委监管 → 上市公司财报 → 行业研究 → 权威媒体，至少 6 次有效检索、覆盖 5 个以上类别；
- 每条判断仍需 T1–T4 标注，禁止用自媒体兜底。

**降级**：走轻量速览版，凡无来源的判断在 `<数据缺口与弥补>` 标 `数据缺失-C`，并在报告头部「数据时效与复核」注明「数据时效性不足，建议复核」。

---

## 11. 图表单位不对（换行业后显示「万吨 / 元每吨」）

**现象**：工程机械、光伏等行业，盈亏图仍显示「万吨」。

**原因**：`params` 中「设计产能」「产品现货单价」缺少 `unit`，模板回落为通用占位。

**处置**：为这两项补 `unit`，例如产能写 `台/年`、单价写 `万元/台`；金额类参数写 `亿元` 或 `万元`，模板会自动换算到万元。

**降级**：无单位时模板显示「单位 / 元每单位」，图仍可出，但可读性差；属数据质量问题，应补。

---

## 12. 打包或上架 dry-run 报错

**现象**：`publish --dry-run` 返回缺字段或版本号非法。

**原因**：`SKILL.md` frontmatter 缺 `slug` / `version` / `displayName`，或 `version` 不是 `x.y.z` 形式。

**处置**：核对 frontmatter 三项齐全、版本号与 `skill-dependencies.json` 一致；发布包须剔除本机安装态文件（`_meta.json`、`_skillhub_meta.json`）。

**降级**：无。上架前预检必须通过。

## 附：常见误判（不是故障）

| 看到的 | 说明 |
|---|---|
| 源码里搜到 `undefined` / `NaN` | 那是渲染层的兜底与清洗逻辑本身，不代表页面异常；应检查 `<script>` 之外的正文 |
| 轻量版没有专项三内容 | 设计如此，`applicable=false` 时整章收起并说明原因 |
| 风险等级颜色与「高/中/低」字面不一一对应 | 判定徽标按信贷语义着色（如「显著低于行业均值」为红、「略低于」为橙），不按字面高低 |
| 专项三标注「行业基准示例值」 | 该表是行业基准模板，非目标企业可研数据；实际准入须以企业真实成本结构复核 |
