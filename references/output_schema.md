# 输出结构定义（Output Schema）

本文件定义行业尽调报告必须输出的完整 XML 标签体系、全局约定与枚举值。生成报告时严格遵循，违反即视为不合格输出。

---

## 全局约定（模型必须遵守）

1. **数据缺失**：任何字段确无数据，必须填"数据缺失-X"。X 取值如下，并在所在维度的 `<数据缺口与弥补>` 中给出替代方案：
   - A：行业无上市公司对标（高度细分或新兴行业，暂无 A 股同行业上市公司）
   - B：该指标非行业通用披露项（如部分轻资产行业不披露产能利用率）
   - C：数据源暂时不可用（联网检索未获取到有效数据，建议通过 Wind 等付费终端补充）
   - D：行业特殊不适合此指标（如金融行业不适用存货周转率）

2. **数值精度**：所有数值型字段须同时标注单位与数据时间区间。例："58.3%（基于 23 家 A 股上市公司 2025 年报加权平均）"。

3. **确定性标识**：每个分析维度须用 `<数据确定性>` 区分"确凿数据"与"合理推断"，不确定性诚实披露。

4. **红色预警同步**：除报告头部外，任一维度触发红色预警条件时，须在该维度 `<维度红色预警>` 同步标注【⚠️ 红色预警】及事由。

5. **禁止模糊词**：严禁"比较好/还可以/一般般/有一定风险"等表述，判定一律用规定枚举值。

6. **专项模块规则**：四大专项模块（核心风险深度分析、目标区域实操核查清单、盈亏测算模板、ESG与绿色信贷适配度）为默认必输出项，不得删除标签；若模块存在行业不适用场景，须标注不适用并说明原因代码。
7. **来源分级（T1–T4）**：每条`<数据来源>`必须标注信源等级，编码规则与映射见 `references/source_tiers.md`。等级自高到低为 T1 一手权威 / T2 官方自述 / T3 独立第三方 / T4 个人与存疑；T4 不得单独支撑任何结论，仅作线索且须与 T3 交叉印证。模型在来源字符串前置【T1】–【T4】标记，使溯源成为硬性约束。

---

## 维度核心能力对照

| 维度 | 核心研判目标 | 关键枚举值 |
| --- | --- | --- |
| 维度一 政策导向 | 政策属性与趋势 | 扶持类/限制类/淘汰类/未明确但无限制/未明确但有隐忧 |
| 维度二 周期阶段 | 生命周期位置 | 上行期/平稳期/下行期/底部震荡/拐点不明 |
| 维度三 盈利水平对标 | 企业与行业均值偏离 | 显著高于/略高于/持平/略低于/显著低于/无法对标 |
| 维度四 产能供需 | 供需格局 | 供需平衡/供给过剩/供给紧缺/结构性过剩/结构性紧缺 |
| 维度五 行业财务指标均值 | 行业基准标尺 | 基于上市公司样本的均值、中位数、合理区间、警戒线 |
| 维度六 行情研判 | 全国与区域现状及前景 | 整体向好/平稳运行/承压下行/结构性分化/前景不明 |
| 维度七 产业链位势与议价能力 | 产业链位置与议价能力 | 优势/中性/弱势 |

风险雷达五级：政策、周期、盈利、供需、财务，各 1(最低)-5(最高)，综合风险得分为五项平均分（保留一位小数）。维度七（产业链位势）与专项四（ESG与绿色信贷）不纳入雷达评分轴，但作为综合评估与信贷策略的关键输入，并以"合规与制裁风险"字段单独披露。

五维评分口径（HTML 报告「五维评分口径说明」以此为准）：
- 分值方向：五个评分轴各取 1–5 分，分值越高表示该维度信贷风险越大；1 风险很低、2 风险较低、3 风险中等、4 风险较高、5 风险很高。综合得分为五项算术平均（保留一位小数），同样按 1→5 风险递增；分值表示相对风险位次，不是违约概率。
- 政策：按产业目录定位与监管导向判分，扶持/中性且无信贷限制 1–2，政策转向或隐性约束 3，限制类或压降导向 4，淘汰类或明确压降信贷规模 5。
- 周期：按营收利润趋势、资本开支、库存与领先指标判分，上行期 1–2，平稳期 3，下行或拐点不明 4，持续下行且无改善 5。
- 盈利：以上市公司样本行业均值为标尺，显著高于均值 1–2，持平 3，略低于 4，显著低于或亏损面扩大 5；无企业财务数据时按行业整体盈利状况判分并标注「行业基准」。
- 供需：按产能利用率、库存与价格信号判分，供需平衡或紧缺 1–2，结构性分化 3，结构性过剩或价格持续下行 4，全面过剩且利用率长期低于警戒线 5。
- 财务：按负债率、经营现金流/净利润、应收与存货周转、亏损面判分，指标稳健 1–2，基本持平 3，周转恶化或现金流走弱 4，高杠杆叠加持续亏损 5。
- 边界：维度七与专项四不纳入五轴评分；缺证据的维度标注「未验证」，不以模型记忆补分。
