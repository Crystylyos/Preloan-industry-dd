# 用户查询模板（User Prompt Template）

信贷调查人员填写 `{...}` 中的占位符后，与 System Prompt（即本技能的角色与输出规范）一起提交。本技能执行时，由模型直接代入以下要素并产出报告与 HTML 页面。

---

请对以下行业进行贷前行业尽调分析，按系统指令中的 XML 格式输出完整报告。同时，额外生成一份配套 HTML 展示页面。

## 目标行业

{填写行业名称，如"光伏制造""生猪养殖""房地产开发""医疗器械"}

## 目标企业基本信息（如有）

- 企业名称：{企业全称}
- 主营产品/服务：{简要描述}
- 2025年营收：{金额，单位万元}
- 2025年净利润：{金额，单位万元}
- 资产负债率：{百分比}
- 应收账款周转率：{次数}
- 存货周转率：{次数}
- 净资产收益率（ROE）：{百分比}
- 营业利润率：{百分比}
- 净利润率：{百分比}

## 特别关注点

{填写信贷调查中特别关注的行业风险点，如"中美贸易摩擦影响""原材料价格波动""环保限产政策"}

## 可用数据源提示

{如已从巨潮/Wind/同花顺妙想/企查查等处预先下载或已连接 MCP 获取行业与企业数据，可在此简要列出，引导模型优先使用，如"已取得光伏行业23家A股上市公司2025年报财务数据，详见附件；环境已连接Wind与企查查MCP"}

## 输出模式

{完整版（默认，含企业财务对标与盈亏测算）| 轻量速览版（仅行业层面研判，无需企业提供财务数据）}

## HTML 配套页面输出要求

1. 同步生成一份配套 HTML 可视化展示页面，必须满足以下要求：
2. 风格要求：页面风格专业严谨，适配银行内部审批场景，配色沉稳，结构清晰，无冗余装饰元素。
3. 内容要求：完整呈现 XML 报告的全部内容，七大基础维度加四大专项模块默认全量展示，按章节分块排版。
4. 雷达图要求：风险雷达评分必须以交互式雷达图形式展现，刻度与报告中 1-5 分制完全对应，支持悬停查看数值。
5. 专项模块展示：核心风险按四档分级色卡呈现（高风险红、中高风险橙、中风险黄、低风险绿）；判定徽标按信贷语义着色，低于 / 弱于 / 不达标等负面结论一律红橙警示，利好结论绿色，不得按字面「高 / 中 / 低」着色；核查清单采用分栏排版；测算模板采用表格化展示，压力测试高亮标注。
6. 兼容性要求：页面自适应 PC 端显示，为单文件 HTML，全站字体统一微软雅黑，无需额外依赖，双击即可打开使用；含侧栏目录、暗色主题与 A4 打印样式。
7. 轻量版 / 完整版自适应：专项三由 `special.projectCalc.applicable` 控制，维度三按有无企业值自动收放列；页面样式固定，只按 `references/html_ui_spec.md` 契约填入 `REPORT_DATA`。

---

注：本技能实际执行时，上述占位符由用户在对话中提供，模型按 `references/output_schema.md` 的结构产出报告，并基于 `assets/report_template.html` 生成交付页面。如需 Word/PDF 交付，将 `REPORT_DATA` 导出为 `report_data.json` 后运行 `assets/generate_docx.py` 即可。无需用户手动拼接提示词。
