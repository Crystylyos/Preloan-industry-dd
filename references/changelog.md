# preloan-industry-dd 版本沿革

## v5.4.0（2026-11-12）

- HTML 可视化页面改用 UI v2 契约：固定 15 章节、侧栏与横滑目录、暗色主题、A4 打印、四档风险色阶；全站字体统一微软雅黑。
- 生成方式改为数据与表现分离：只产出 `REPORT_DATA`，模板保留 `__REPORT_DATA__` 占位符，数据块逐字注入。
- 补齐轻量版 / 完整版自适应：专项三由 `projectCalc.applicable` 控制，维度三企业值列按有无企业值自动收放；渲染层增加缺字段兜底，页面不出现 `undefined` / `NaN`。
- 新增 `references/html_ui_spec_v2.md`（UI 契约与验收清单）；`assets/report_template.html` 随之更新。
- 专项三渲染增强（同版本补丁，不升版本号）：适用场景与测算假设改为长文本提示块；新增由 `firstYear` 中 EBIT 值驱动的「基准情景判定」；`metrics` / `stress` 的「不达标」「不可接受」改红色徽标、「审慎」橙色；信贷准入阈值拆为正常 / 审慎 / 严禁三块并突出一票否决；来源串中多个【T1】–【T4】标签全部渲染为分级徽标；四张表字段统一走缺值兜底。改动仅限 `sec-10` 渲染，数据契约与其余章节不变。
- 判定徽标统一改为信贷语义色阶（同版本补丁）：新增 `TONE_RULES` / `semanticTone()`，按优先级先排除「低于警戒线」等正面例外、再判风险评级、最后判负面业绩词；「显著低于行业均值」「不达标」「不可接受」「严禁新增」等改红色，「略低于 / 弱于 / 偏低 / 审慎」等改橙色，「显著高于行业均值」「扶持类」等改绿色，中性值保持灰色。`enumPill()` / `enumClass()` 与专项三 `pcPill` 全部同源，不再按字面「高 / 中 / 低」着色。同步 `SKILL.md`、`references/html_ui_spec_v2.md` §5.3 与附录 B、`references/user_prompt_template.md`；数据契约与 `output_schema.md` 枚举值不变。
- 专项三新增盈亏平衡曲线图（同版本补丁）：在适用分支（完整版 `applicable=true`）新增 `buildBreakeven()` 原生 SVG 图，直观展示总收入/总成本线、盈亏平衡点、设计产能约束区与满产亏损；固定成本与单位变动成本由基础参数表与首年总成本反推（自洽复现 EBIT -0.21 亿元口径），并附「不亏损临界条件」与「测算口径」说明，明确其为行业基准示例拆分、非目标企业真实成本结构。专项三标题由「单项目收益测算模板」更名为「盈亏测算模板」。轻量版与 `applicable=false` 不渲染该图。
- 新增「质量底线：交付前独立返检」章节（SKILL.md，同版本补丁）：任何数据交付物定稿 / 上架 / 分发前须完成一次独立于生成流程的返检（跨工具渲染校验 / 逐项独立核对 / 目视抽样至少一项），强制覆盖数据完整、结构完整、口径标注、版式、合规五项，未通过不得定稿；并规定回归测试对照数据须来自技能工作区 `verification/` 受控样本，禁止回归脚本硬编码读取桌面等外部文件路径。
- 根目录新增 `变更说明.md`：基于字节级真实比对，逐文件列出从原版 v1.0.2 到 v5.4.0 的全部变更（改写 / 新增 / 未变），明确业务框架、数据契约、Word 生成、来源分级、校验脚本均字节级未动，供上架审核参考。
