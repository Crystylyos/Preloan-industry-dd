本次为**表述统一**修订，不改任何分析框架、字段与判定逻辑。

- **正文标题对齐**：`SKILL.md` 一级标题由「商业银行贷前行业尽调（AI 报告生成）」改为「商业银行贷前行业尽调与报告生成」，与 frontmatter `displayName` 及 README 保持一致。
- **概述措辞调整**：删去「将方法封装为可直接执行的 Skill」「模型在执行时扮演」这类元描述，改为直述「本技能在执行时，将扮演"商业银行授信审批部高级行业研究员"」；`description` 中「该技能驱动模型扮演」同步改为「本技能在执行时将扮演」。
- **专项三命名全文统一**：`单项目收益测算模板` → `盈亏测算模板`（该名称自 v5.4.0 起已在页面使用，文档与脚本此前未跟上）。涉及 `SKILL.md`（概述、输出模式、轻量路径、description）、`references/output_schema.md`（四大专项列举与 XML 标签 `<专项三_盈亏测算模板>`）、`references/user_prompt_template.md`、`references/troubleshooting.md`、`assets/generate_docx.py`（Word 章节标题与默认说明）、`assets/report_template.html`（章节注释与不适用兜底文案）、`examples/report_data_nonproject.json`。`references/changelog.md` 与 `变更说明.md` 保留更名事实，不回改历史记录。
- 回归：三场景分支（冲突 / 正常 / 轻量）与跨行业盈亏图（麦芽「万吨」/工程机械「台」）全部通过；自检 28/28；三份样例 JSON 与三个脚本语法校验通过。

## v5.4.2（2026-11-13）

本轮针对 SkillHub TRACE 评测（可靠性 / 规范性 / 有效性三项扣分项）整改，重点是**换行业不再出错**与**两份交付物色阶统一**。

- **盈亏平衡图参数化（修复跨行业错图）**：旧实现把麦芽行业假设写死在代码里——固定费用 339 万元、折旧 10 年、「万吨」「元/吨」文案、Y 轴 0–40000 万元刻度、`设计产能 || 10`。换到工程机械（台、万元/台）或光伏（元/W、MW）会把数字按错误单位绘制。现改为：产能与价格单位取自 `params[].unit`，金额按 `亿元/万元/元` 自动换算到万元，坐标刻度按数据量级自适应（`niceStep`），折旧年限与其他固定费用由可选 `projectCalc.chart` 覆盖（缺省 10 年 / 0）。
- **修复区间数值解析缺陷**：旧 `num()` 剔除所有非数字字符，`"3500 至 4000"` 会被拼成 `35004000`、`"3.5 至 4.0"` 拼成 `3.54`，导致测算基准失真。现改为提取数字序列、区间取中值，并支持「约 911」这类带文字写法。
- **移除行业专属文案**：删除「参考本报告敏感性测试：单价回升至 3600 元/吨且利用率 85% 时 EBIT +0.17 亿元」与「已复现 EBIT -0.21 亿元」等麦芽专项表述，改为由当前数据动态生成。
- **Word 风险色对齐 HTML 四档（修复交付物色阶不一致）**：`generate_docx.py` 旧逻辑按「含高即红」判定，「中高风险」被染成高风险色，四档塌成三档，且色值（#D23B3B/#D9A300/#2E9E5B）与页面（#C0392B/#D2742B/#B78A21/#1E7A52）完全不同。现改为四档逐值同源，判定顺序先「中高」后「高」，并抽出 `hex_rgb()` 复用。
- **新增 `references/troubleshooting.md`**：30 秒定位表 + 12 类故障的「现象 / 原因 / 处置 / 降级」四段式，覆盖网络与数据源不可用、缺字段、占位符未替换、校验不通过、Word 依赖缺失、图表单位错误、打包 dry-run 失败等；附「常见误判」区分真故障与设计行为。
- **新增 `examples/` 与 `assets/selftest.py`**：三份可直接运行的最小 `REPORT_DATA`（完整版项目制 / 轻量速览版 / 非项目制）+ 用法说明；自检脚本一键完成「模板结构 / 样例注入 / 零外部依赖 / 专项三契约 / 色阶同源」检查，`--browser` 可追加真实渲染核验。
- **非项目制例外规则**：校验器此前对「完整版 + `applicable=false`」一律判不合格，会误伤合法的非项目制行业。现补充例外——`note` 注明「非项目制」或「数据缺失-D」即放行；标记与数据矛盾（有测算数据却写 false）仍判不合格。
- **版本引用统一**：`validate.py`、`check_environment.py` 头部过期版本标注改为能力引入说明；交付目录移除本机安装态残留 `_meta.json` / `_skillhub_meta.json`。
- **校验器重构**：抽出 `check_html_structure()` 供 `validate.py` 与 `selftest.py` 共用，避免两套判据漂移。

## v5.4.1（2026-11-13）

- 修复专项三「盈亏测算模板」整章不渲染的缺陷：旧实现仅凭 `special.projectCalc.applicable===false` 一个字段决定分支，模型一旦误填 `false`，即便已产出基础参数 / 首年测算 / 评价指标 / 压力测试全套数据，整章也只剩一句「不适用说明」——与原版「项目制行业默认输出测算模板」的行为不一致。模板改为**数据优先**判定：存在测算数据即渲染，仅在「明确标记不适用且四张表全空」时收起整章；`applicable` 宽松解析（兼容 `"false"` / `0`），标记与数据冲突时照常渲染并给出复核提示，标记为适用却无数据时提示数据缺口。
- `assets/validate.py` 新增专项三一致性校验：完整版 `applicable=false`、标记与数据矛盾、`applicable=true` 但数据低于门槛（`params`≥8 / `firstYear`≥4 / `metrics`≥4 / `stress`≥4）、`applicable` 非布尔值，均判不合格并阻断交付。
- `SKILL.md` 步骤一「输出模式」与步骤五「轻量版 / 完整版自适应」、`references/data_contract.md` 同步补充「专项三开关须与输出模式严格对齐」硬规则：完整版必须为 `true` 且满足门槛，仅轻量速览版可为 `false`。
- 回归证据：三个受控样本（数据完备+false / 数据完备+true / 真轻量版）经无头浏览器渲染核验全部符合预期，去 `<script>` 后 `undefined` / `NaN` 计数为 0，`sec-10` 目视无溢出重叠；历史报告中误填 `false` 的一份被校验器精准拦截。

## v5.4.0（2026-11-12）

- HTML 可视化页面改用 UI v2 契约：固定 15 章节、侧栏与横滑目录、暗色主题、A4 打印、四档风险色阶；全站字体统一微软雅黑。
- 生成方式改为数据与表现分离：只产出 `REPORT_DATA`，模板保留 `__REPORT_DATA__` 占位符，数据块逐字注入。
- 补齐轻量版 / 完整版自适应：专项三由 `projectCalc.applicable` 控制，维度三企业值列按有无企业值自动收放；渲染层增加缺字段兜底，页面不出现 `undefined` / `NaN`。
- 新增 `references/html_ui_spec_v2.md`（UI 契约与验收清单）；`assets/report_template.html` 随之更新。
- 专项三渲染增强（同版本补丁，不升版本号）：适用场景与测算假设改为长文本提示块；新增由 `firstYear` 中 EBIT 值驱动的「基准情景判定」；`metrics` / `stress` 的「不达标」「不可接受」改红色徽标、「审慎」橙色；信贷准入阈值拆为正常 / 审慎 / 严禁三块并突出一票否决；来源串中多个【T1】–【T4】标签全部渲染为分级徽标；四张表字段统一走缺值兜底。改动仅限 `sec-10` 渲染，数据契约与其余章节不变。
- 判定徽标统一改为信贷语义色阶（同版本补丁）：新增 `TONE_RULES` / `semanticTone()`，按优先级先排除「低于警戒线」等正面例外、再判风险评级、最后判负面业绩词；「显著低于行业均值」「不达标」「不可接受」「严禁新增」等改红色，「略低于 / 弱于 / 偏低 / 审慎」等改橙色，「显著高于行业均值」「扶持类」等改绿色，中性值保持灰色。`enumPill()` / `enumClass()` 与专项三 `pcPill` 全部同源，不再按字面「高 / 中 / 低」着色。同步 `SKILL.md`、`references/html_ui_spec_v2.md` §5.3 与附录 B、`references/user_prompt_template.md`；数据契约与 `output_schema.md` 枚举值不变。
- 专项三新增盈亏平衡曲线图（同版本补丁）：在适用分支（完整版 `applicable=true`）新增 `buildBreakeven()` 原生 SVG 图，直观展示总收入/总成本线、盈亏平衡点、设计产能约束区与满产亏损；固定成本与单位变动成本由基础参数表与首年总成本反推（自洽复现 EBIT -0.21 亿元口径），并附「不亏损临界条件」与「测算口径」说明，明确其为行业基准示例拆分、非目标企业真实成本结构。专项三标题由「单项目收益测算模板」更名为「盈亏测算模板」。轻量版与 `applicable=false` 不渲染该图。
- 新增「质量底线：交付前独立返检」章节（SKILL.md，同版本补丁）：任何数据交付物定稿 / 上架 / 分发前须完成一次独立于生成流程的返检（跨工具渲染校验 / 逐项独立核对 / 目视抽样至少一项），强制覆盖数据完整、结构完整、口径标注、版式、合规五项，未通过不得定稿；并规定回归测试对照数据须来自技能工作区 `verification/` 受控样本，禁止回归脚本硬编码读取桌面等外部文件路径。
- 根目录新增 `变更说明.md`：基于字节级真实比对，逐文件列出从原版 v1.0.2 到 v5.4.0 的全部变更（改写 / 新增 / 未变），明确业务框架、数据契约、Word 生成、来源分级、校验脚本均字节级未动，供上架审核参考。
